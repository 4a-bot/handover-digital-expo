# 專案範圍

版本：1.0  
日期：2026-11-16  
正式名稱：交接有據｜數位展務工作台

## 主要任務

協助首次參與或中途接手的工作人員理解數位作品展的籌備狀態，找到正確的作品資料與文件，依指引完成展示、處理問題並交付下一位接手者。

網站的主要成果是可操作的交接手冊。兩個真正可使用的小工具作為示範展品，讓收件、展示、驗證與改版流程都有實際材料。

## 使用對象與查找方式

- 籌備負責人：確認階段、分工、未完成事項。
- 展品整理人員：確認作品資料、展示版本及相關文件。
- 現場工作人員：試跑範例、介紹作品、尋找備援。
- 接手者：理解已完成內容、問題、決策與下一步。

首頁已選定展務工作台：先顯示任務、接手狀態與待確認事項。

## 首批示範作品

### 清單整理器

貼上逐行清單，選擇空白與重複項目的處理方式，查看整理結果、移除數量，並複製或下載。保留原先順序與首筆內容，不進行模糊比對或語意改寫。

### 展品說明牌產生器

輸入作品名稱、形式、介紹及選填署名，檢查必填與長度，預覽說明牌並列印。空資料與過長內容要提示，不能靜默刪改文字。

每個工具都附展示入口、範例輸入、預期結果、工作人員指引、已知限制與備援材料。工具邏輯與網站介面分開維護。

## 網站內容

1. 接手總覽：目的、目前階段、職責與尚待確認事項。
2. 六個流程：企劃、收件、展示準備、現場執行、撤展、結案交接。
3. 展品檔案：與任務、操作說明、版本、備援互相連結。
4. 五份範本：專題收件表、展示需求表、設備檢查表、現場示範操作表、問題與交接紀錄表。
5. 三類例外：入口不可用、裝置或輸入不符條件、更新後文件不同步。
6. 規則與修訂說明：展示新增與改版如何依 AGENTS.md 完成。

每份範本提供空白檔、完整示例與使用說明。情境資料標示為示範；實際程式驗證另行記錄。

## 完成證據

- 公開 GitHub Repository 與可瀏覽網站。
- 兩件可操作的示範作品及操作結果。
- 有內容、有關聯、有下載檔的完整流程。
- AGENTS.md 初稿到修訂版的實際變化。
- 一次新增內容與一次修改既有內容的檔案差異及檢查結果。
- 五項正式繳交內容的整理稿。

## 已定案的呈現

首頁優先呈現任務與接手狀態；正式視覺為深色展場。網站保留其他閱讀主題作為偏好切換。六階段現有十三項任務，包含依規則新增的換班交接單元。
