## 發現與修正

1. 原生 replaceChildren 接受陣列時，搜尋結果被轉成網址文字；改用先展平子節點的共用 replace 函式，同步修正流程列表，再以瀏覽器重測搜尋與職務篩選。
2. 圖示任務按鈕缺少名稱；補上可辨識的 aria-label。
3. 窄版主操作原先被 CSS 隱藏；恢復新增與匯出入口。
4. 手機遮罩中心落在側欄範圍；將遮罩限於側欄外，重測關閉後維持工作台頁面。
5. 交接表單缺少 input type 造成未套用共用樣式；補上文字輸入型別與間距。
6. 靜態備援連結的下載事件未完成；改用有錯誤回報的檔案取得與 Blob 下載，重測取得 HTML。
7. F01、F02 的範例還描述工具未完成；更新為目前可操作版本、真實相對入口及剩餘實機檢查，並重產生範本。
